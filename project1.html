Employee Management Application

Web Project - Laravel Framework

Project Description

This project was developed using the Laravel framework and MySQL database. It is a web-based employee information system that allows administrators to input and store comprehensive employee data. I submitted this project as an innovation initiative for the assistant selection process at the Computer Development Institute (LepKom) of Gunadarma University for the 2023/2024 period.

My Role

Lead developer responsible for designing the UI, implementing CRUD functionalities, and integrating the MySQL database with Laravel Framework.

Project Duration

Start: 13 August 2023 | End: 24 August 2023

Project Outcome

Successfully delivered a stable application that manages employee data with features such as admin login, add/edit/delete data. The system worked smoothly during the final presentation.
